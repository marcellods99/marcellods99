# Texto Utils

Mini projeto de utilitários de texto em Python dentro do perfil.

## Funcionalidades

- Converter texto para maiúsculas
- Converter texto para minúsculas
- Remover espaços duplicados
- Substituir caracteres
- Mascarar letras

## Como executar

```bash
python texto-utils/main.py
```

## O que aprendi

- Manipulação de strings
- Funções de texto
- Interface simples de linha de comando
