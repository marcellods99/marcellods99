# 🧮 Calculadora com Análise

Calculadora em Python que realiza uma operação entre dois números e também analisa características dos valores informados.

---

## 📋 Sobre o Projeto

Este é um projeto prático desenvolvido durante a formação Python para praticar:
- Estruturas condicionais (`if/elif/else`)
- Operações matemáticas
- Operadores ternários
- Verificação de paridade
- Análise de números inteiros ou decimais

---

## 🚀 Como Rodar

### Pré-requisitos
- Python 3.6+ instalado

### Executar o programa

```bash
python main.py
```

Ou:

```bash
python3 main.py
```

---

## 🎯 Conceitos Praticados

✅ **Condicionais** - Escolha da operação matemática  
✅ **Operadores** - Soma, subtração, multiplicação e divisão  
✅ **Operador Ternário** - Classificação dos números em uma linha  
✅ **Módulo** - Verificação de par ou ímpar com `%`  
✅ **Comparações** - Análise dos valores digitados  

---

## 💡 O que Aprender Aqui

Este projeto demonstra como combinar várias lógicas em um único programa:
- Receber dois números do usuário
- Escolher uma operação matemática
- Calcular o resultado
- Analisar propriedades dos números digitados
- Exibir uma saída organizada no terminal
