# 🌡️ Média de Temperaturas

Programa em Python que calcula a média de temperaturas informadas pelo usuário até receber um valor de parada.

---

## 📋 Sobre o Projeto

Este é um projeto prático desenvolvido durante a formação Python para praticar:
- Laços de repetição (`while`)
- Condição de parada
- Acumulador e contador
- Cálculo de média
- Validação para evitar divisão por zero

---

## 🚀 Como Rodar

### Pré-requisitos
- Python 3.6+ instalado

### Executar o programa

```bash
python main.py
```

Ou:

```bash
python3 main.py
```

---

## 🎯 Conceitos Praticados

✅ **Loops** - Repetição com `while`  
✅ **Condição de Parada** - Encerramento ao informar `-273`  
✅ **Acumulador** - Soma dos valores digitados  
✅ **Contador** - Quantidade de temperaturas válidas  
✅ **Média Aritmética** - Divisão da soma pela quantidade  

---

## 💡 O que Aprender Aqui

Este projeto demonstra boas práticas para iniciantes em Python:
- Como receber uma quantidade indeterminada de dados
- Como usar uma condição para encerrar o programa
- Como calcular média usando soma e contador
- Como tratar o caso em que nenhum valor válido foi informado
