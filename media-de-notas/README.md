# Média de Notas

Mini projeto que calcula a média de três notas de um estudante.

## Como executar

```bash
python main.py
```

> Código original de `Alura Python/Exercicios/Aula 2/Calculadora com operadores/ex009.py`.

## Sobre o código

O programa lê três notas do usuário, calcula a média simples e imprime o resultado formatado. A lógica é direta e mostra como trabalhar com entrada de dados, conversão de tipos e operações aritméticas.
