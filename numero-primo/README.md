# 🔢 Número Primo

Programa em Python que verifica se um número inteiro é primo.

---

## 📋 Sobre o Projeto

Este é um projeto prático desenvolvido durante a formação Python para praticar:
- Estruturas condicionais (`if/else`)
- Laços de repetição (`for`)
- Operador módulo (`%`)
- Controle de fluxo com `break`
- Raciocínio matemático aplicado à programação

---

## 🚀 Como Rodar

### Pré-requisitos
- Python 3.6+ instalado

### Executar o programa

```bash
python main.py
```

Ou:

```bash
python3 main.py
```

---

## 🎯 Conceitos Praticados

✅ **Condicionais** - Decisões com `if/else`  
✅ **Loops** - Repetição com `for`  
✅ **Break** - Interromper o laço quando encontrar um divisor  
✅ **Booleanos** - Uso de variável de controle (`eh_primo`)  
✅ **Matemática** - Verificação de divisibilidade  

---

## 💡 O que Aprender Aqui

Este projeto demonstra conceitos importantes para iniciantes em Python:
- Como testar divisibilidade usando `%`
- Como percorrer possíveis divisores com `range()`
- Como usar uma variável booleana para controlar o resultado
- Como parar uma repetição quando a resposta já foi encontrada
