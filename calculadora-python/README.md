# Calculadora Python

Mini projeto de calculadora em Python dentro do perfil.

## Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão
- Média ponderada fixa

## Como executar

```bash
python calculadora-python/main.py
```

## O que aprendi

- Entrada de dados com `input()`
- Tratamento de erros com `try/except`
- Estruturas condicionais com `if/elif/else`
