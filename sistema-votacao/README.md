# Sistema de Votação

Mini projeto de votação em Python dentro do perfil.

## Funcionalidades

- Votação em quatro candidatos
- Votos nulos e em branco
- Contagem e exibição dos resultados
- Definição do vencedor

## Como executar

```bash
python sistema-votacao/main.py
```

## O que aprendi

- Contagem com dicionários
- Estruturas de repetição
- Validação de entrada do usuário
