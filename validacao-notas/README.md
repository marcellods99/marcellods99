# ✅ Validação de Notas

Programa em Python que recebe 15 notas e valida se cada uma está dentro do intervalo permitido.

---

## 📋 Sobre o Projeto

Este é um projeto prático desenvolvido durante a formação Python para praticar:
- Laços de repetição (`for`)
- Validação com `while`
- Entrada de dados com `input()`
- Condições lógicas
- Repetição até o usuário informar um valor válido

---

## 🚀 Como Rodar

### Pré-requisitos
- Python 3.6+ instalado

### Executar o programa

```bash
python main.py
```

Ou:

```bash
python3 main.py
```

---

## 🎯 Conceitos Praticados

✅ **For** - Repetição por quantidade definida  
✅ **While** - Repetição enquanto a nota for inválida  
✅ **Validação** - Aceita apenas valores entre 0 e 5  
✅ **Operadores Lógicos** - Uso de `or` para testar limites  
✅ **Entrada de Dados** - Leitura de notas pelo terminal  

---

## 💡 O que Aprender Aqui

Este projeto demonstra um padrão muito usado em programação:
- Repetir uma tarefa por uma quantidade fixa de vezes
- Validar dados digitados pelo usuário
- Pedir novamente quando o valor não atende à regra
- Separar a lógica de repetição principal da lógica de validação
