# Coleta de Dados

Mini projeto de coleta de dados em Python dentro do perfil.

## Funcionalidades

- Leitura de nome, idade e altura
- Validação de entrada numérica
- Saída formatada
- Classificação de maioridade

## Como executar

```bash
python coleta-dados/main.py
```

## O que aprendi

- Tratamento de entrada com `try/except`
- Formatação de saída
- Uso de funções para organizar o código
